## 1. ИСПОЛЬЗОВАНИЕ ОБЪЕКТОВ СВОИХ КЛАССОВ В ПОСЛЕДОВАТЕЛЬНЫХ КОНТЕЙНЕРАХ STL

### 1.1. Цель работы

Овладение навыками разработки собственных классов на языке Си++ с перегрузкой операций, организации хранения объектов пользовательских классов в последовательных контейнерах стандартной библиотеки шаблонов STL (`std::list`, `std::vector`), а также применения стандартных алгоритмов копирования (`std::copy`) и методов сортировки.

### 1.2. Условие задачи

В соответствии с **вариантом № 20** необходимо разработать приложение со следующими параметрами:

1. Реализовать класс «Автомобиль» (`Car`), содержащий поля:

    * название модели (`model`);

    * массив расходов топлива из 3-х элементов: на трассе, в городе, смешанный (`fuel`);

    * максимальная скорость (`velocity`);

    * мощность (`power`).

2. Организовать исходный последовательный контейнер `std::list<Car>`, элементами которого являются непосредственно объекты класса (не указатели).

3. Реализовать в классе необходимые конструкторы, обосновать отсутствие или наличие необходимости в конструкторах копирования и перемещения, а также перегруженных операциях присваивания с копированием и перемещением.

5. Считать исходные данные из текстового файла `input.txt`.

6. Скопировать исходный контейнер `std::list<Car>` в целевой контейнер `std::vector<Car>` с помощью алгоритма `std::copy`.

7. Выполнить сортировку объектов в исходном контейнере `std::list<Car>` по смешанному расходу топлива (3-й элемент массива расходов) с использованием метода `list::sort()` без параметров.

8. Вывести в выходной текстовый файл `output.txt` исходный контейнер, контейнер после сортировки и скопированный контейнер, используя перегруженную операцию вставки в поток `<<`.

### 1.3. Текст программы с комментариями

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <fstream>
#include <string>
#include <algorithm>
#include <iterator>
using namespace std;
class Car
{
    string model;
    vector <double> fuel;
    int velocity;
    int power;
public:
    Car() {
        model = "Unknown";
        fuel = {0.0, 0.0, 0.0};
        velocity = 0;
        power = 0;
    }
    Car(string m, vector<double> f, int v, int p) : model(m), fuel(f), velocity(v), power(p) {}
    //конструкторы копирования, перемещения и операторы присваивания писать не нужно
    //в классе нет указателей и динамической памяти, а string и vector сами правильно копируются и чистят память

    //перегрузка оператора < для сортировки list::sort() без параметров
    bool operator<(const Car& other) const {
        return fuel[2] < other.fuel[2];
    }

    //перегрузка оператора вывода в поток <<
    friend ostream& operator<<(ostream& os, const Car& car) {
        os << "Model: " << car.model
           << ", fuel: " << car.fuel[0] << "/" << car.fuel[1] << "/" << car.fuel[2]
           << ", speed: " << car.velocity
           << ", power: " << car.power;
        return os;
    }
};
int main() {
    //файлы для чтения и записи
    ifstream fin("input.txt");
    ofstream fout("output.txt");

    if (!fin.is_open() || !fout.is_open()) {
        cout << "error opening files" << endl;
        return 1;
    }

    list<Car> carList;
    string m;
    double f1, f2, f3;
    int v, p;
    while (fin >> m >> f1 >> f2 >> f3 >> v >> p) {
        vector<double> tempFuel = {f1, f2, f3};
        Car tempCar(m, tempFuel, v, p);
        carList.push_back(tempCar);
    }
    fout << "Original List\n";
    for (const Car& car : carList) {
        fout << car << endl;
    }
    fout << endl;

    //копирование списка в вектор
    vector<Car> carVector;
    copy(carList.begin(), carList.end(), back_inserter(carVector));
    //сортировка списка методом sort() без параметров
    carList.sort();
    //вывод отсортированного списка в файл
    fout << "Sorted List\n";
    for (const Car& car : carList) {
        fout << car << endl;
    }
    fout << endl;
    //вывод скопированного вектора в файл
    fout << "Copied Vector\n";
    for (const Car& car : carVector) {
        fout << car << endl;
    }
    fout << endl;
    cout << "Data saved to output.txt" << endl;


    fin.close();
    fout.close();

    return 0;
}
```

## 2. СРАВНИТЕЛЬНЫЙ АНАЛИЗ КОНТЕЙНЕРОВ И МЕТОДОВ СОРТИРОВКИ

| Контейнер | Внутренняя структура | Тип итераторов | Способ сортировки | Особенности в программе |
| ----- | ----- | ----- | ----- | ----- |
| `std::list<Car>` | Двусвязный список (узлы в динамической памяти) | Двунаправленные (`Bidirectional`) | Метод класса `list::sort()` без параметров | Не поддерживает произвольный доступ по индексу, поэтому стандартный `std::sort` неприменим; использует встроенный метод `sort()`, опирающийся на перегруженный `operator<`. |
| `std::vector<Car>` | Непрерывный блок памяти (динамический массив) | Произвольного доступа (`Random Access`) | Алгоритм `std::sort(begin, end)` | Заполняется из списка с помощью `std::copy` и адаптера вставки `std::back_inserter`, сохраняя порядок исходного списка до сортировки. |
